# Mathematics

**[The Complete Mathematics Book](Complete_Mathematics_Book.md)** is a single self-study book that goes from primary-school arithmetic to graduate-level mathematics in 54 chapters.

| Part | Level | Chapters |
|---|---|---|
| I | Primary foundations | 1–7 |
| II | Middle school | 8–15 |
| III | High school | 16–28 |
| IV | Calculus | 29–36 |
| V | Undergraduate | 37–46 |
| VI | Graduate | 47–54 |
| VII | Appendices: symbols, formulas, reading list, study plan | — |

Parts I–V have explanations, worked examples, practice problems with answers, and checkpoints. Part VI gives an overview of each graduate subject (main definitions, theorems and exercises) and points to full textbooks in Appendix D.

The maths is written in LaTeX (`$...$`), which GitHub renders automatically.
